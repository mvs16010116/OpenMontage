# Edit Director - Narration Synth Pipeline

## When To Use

Every shot has its material animation MP4s (one transparent MP4 per material),
every section has narration audio, the music bed is locked. You build the
timeline: **one timeline slot per generated shot**, where the shot's materials
OVERLAY the same window (layer order: background → midground → foreground), then
slots concatenate in scene order — plus subtitle style, audio layout, and the
render grammar. The output is the `edit_decisions` artifact.

## Mental Model

A shot is ONE assembled frame: its materials overlay the same window in layer
order (background first, foreground on top), producing one image. Shots then
concatenate in scene order — consecutive sentence-shots, bookends at their slots.
The edit's job is placement + layering, not re-cutting: overlay each shot's
materials, put shot N into timeline slot N, narration at the section starts,
subtitles aligned. Restraint still rules — the piece must breathe, but the
variety comes from skill choice and layer composition (scene plan) not from
re-cutting.

## Process

### 0. Guardrails — No Silent Major Changes

Re-read the brief. STOP and surface if: a different TTS voice was generated than
approved; narration was opted out but the edit wants to add a voice-over; the
approved duration changed materially.

### 1. Place One Timeline Slot Per Shot, Overlay Its Materials

Walk the scene plan in order. Each scene (including bookends) becomes exactly ONE
timeline slot; within the slot, ALL of the scene's materials overlay the same
window:

- `slot.scene_id` = scene id; `slot.window.start/end` = scene window.
- `slot.materials[]` = the scene's material animation assets in `layer` order
  (`background` first, then `midground`, then `foreground`). Each entry carries
  its `asset_id`, `layer`, and `in_seconds`/`out_seconds` = 0.0 → scene window
  (materials are authored to the full window).
- `slot.window` length = `scene.end_seconds - scene.start_seconds`.
- Handle any delta: if a material's render duration ≠ window (skill-capped), trim
  that material to the render length and annotate in `metadata.duration_deltas`.
- `transition_in`/`transition_out`: default `cut`; bookends and the first/last
  shot use `fade_in`/`fade_out`. No wipes/pushes — this pipeline's register is
  documentary-clean.
- `reason` on every slot — one line tying the shot to its section's sentence.

Slot windows come from the SCENE PLAN, which (for a section) splits the window
across sentence-shots proportional to character share. Sum of the slots in a
section = section window. Do not invent new split boundaries at edit time — the
scene plan owns them.

### 2. Enforce Adjacent Variety

Walk slots pairwise. Same full-frame (background) skill in two adjacent slots? The
scene plan should already prevent it — if you see it, go back and re-plan, don't
paper over it at edit time. Foreground overlays are exempt (variety is driven by
the background). Log the check in `metadata.adjacency_notes`.

### 3. Set The Subtitle Contract

Burned whole-line subtitles, generated by the **`ass-subtitle-generator`** skill
(`.agents/skills/ass-subtitle-generator/scripts/build_ass.py`). Do NOT hand-write
colors or hand-tune ffmpeg `force_style` — read that skill and run its generator
so every video gets the same readable result. Key correct values that the skill
encodes:

```json
{
  "subtitles": {
    "enabled": true,
    "style": {
      "font": "MS YaHei",
      "font_size": 68,
      "bold": true,
      "primary_color": "&H00FFFFFF",
      "outline_color": "&H00000000",
      "outline_width": 3,
      "shadow": 0,
      "margin_v": 55,
      "alignment": 2
    },
    "source": "assets/subtitles.ass",
    "max_words_per_line": 16
  }
}
```

- **ASS colors, NOT HTML hex.** `#FFFFFF` silently renders BLACK under ffmpeg's
  `force_style` → libass. The correct form is `&H00FFFFFF` (see the
  ass-subtitle-generator SKILL.md "black-text trap").
- **Short lines, ≤16 chars.** Chinese narration is one short sentence per event —
  a line that wraps beyond the screen is a bug. `--max-chars 16`, `--font-size 68`,
  PlayRes 1920x1080 in the generated `.ass`.
- **Timing respects real narration offsets.** build_ass.py reads
  `script.sections[].start_seconds` (not cumulative narration length) so subtitles
  stay inside each narration window — with opener/chapter-card silence there is no
  drift. The generator's `--script` input must be a flattened `{sections: [...]}`
  file whose `start_seconds` are the real narration starts.
- Bookend scenes (title cards) carry their own typography — no burned subtitles;
  note `subtitles.exclude_scene_ids: ["scene_opener", ...]`.

### 4. Set The Audio Layout

**Narration (spine) + music (support).** The narration master is built with
narration segments **back-to-back** (end of section N = start of section N+1);
the ONLY silence is at the opener and chapter-card holds. Gap-free narration is
what kills the "dead air between chapters" look. Rebuild the mix via
`audio_mixer` (or ffmpeg `adelay`+`amix`) so narration lands at the section
starts:

```json
{
  "audio": {
    "narration": {
      "segments": [
        { "asset_id": "asset_narration_section_02", "start_seconds": 16.564, "end_seconds": 47.572 }
      ]
    },
    "music": {
      "volume": 0.35,
      "fade_in_seconds": 1.0,
      "fade_out_seconds": 3.0,
      "ducking": { "enabled": true, "threshold_db": -20, "reduction_db": 8 }
    }
  }
}
```

Rules:

- **Back-to-back narration.** Narration segments tile without gaps — consecutive
  `end_seconds` = next `start_seconds`. Bookend scenes carry no narration.
- **Deliberate silence only.** Silence is reserved for the opener and chapter
  cards; anywhere else silence is a pacing bug.
- **Windows = real narration durations.** Section window = narration segment
  window (probed duration). The mixed `narration_mix.mp3` total length = last
  narration end, so the final render's audio track covers the timeline.
- Music low (0.25-0.4), ducking ON.

### 5. Lock The Render Grammar (BINDING)

```json
{
  "renderer_family": "narration-synth",
  "render_runtime": "ffmpeg"
}
```

`render_runtime` MUST stay `"ffmpeg"`. Material animation layers are already
rendered at the assets stage (via `npx hyperframes render`); compose overlays them
per shot, concatenates the shots, burns subtitles, and muxes audio through
`video_compose`'s ffmpeg path. A silent swap to Remotion or a full HyperFrames
timeline is a CRITICAL governance violation.

### 6. Emit The Edit Decisions

```json
{
  "version": "1.0",
  "renderer_family": "narration-synth",
  "render_runtime": "ffmpeg",
  "slots": [
    {
      "scene_id": "scene_opener",
      "window": { "start": -1.0, "end": 2.0 },
      "materials": [
        { "asset_id": "asset_scene_opener_mat", "layer": "background", "in_seconds": 0.0, "out_seconds": 3.0 }
      ],
      "transition_in": "fade_in",
      "transition_out": "cut",
      "reason": "opener — center title card under the hook"
    },
    {
      "scene_id": "scene_02",
      "window": { "start": 5.5, "end": 14.0 },
      "materials": [
        { "asset_id": "asset_scene_02_mat_bg", "layer": "background", "in_seconds": 0.0, "out_seconds": 8.5 },
        { "asset_id": "asset_scene_02_mat_fg", "layer": "foreground", "in_seconds": 0.0, "out_seconds": 8.5 }
      ],
      "transition_in": "cut",
      "transition_out": "cut",
      "reason": "scene_02 — map background + fleet-bar overlay under the corridor sentence"
    }
  ],
  "audio": { "...": "as above" },
  "subtitles": { "...": "as above", "exclude_scene_ids": ["scene_opener"] },
  "metadata": {
    "pipeline": "narration-synth",
    "scene_count": 6,
    "hero_scenes": ["scene_opener", "scene_02"],
    "total_duration_seconds": 93.0,
    "adjacency_notes": [],
    "duration_deltas": []
  }
}
```

### 7. Quality Gate

- `renderer_family = "narration-synth"` and `render_runtime = "ffmpeg"` carried
  unchanged from proposal.
- One timeline slot per SHOT; a section's sentence-shots are consecutive slots
  whose windows sum to the section window.
- Every slot lists ALL its materials in layer order (background → midground →
  foreground); each material within a slot spans the SAME window (overlay, not
  concat).
- Bookends present at opener + chapter breaks with no narration attached.
- `subtitles.enabled = true`, generated by `ass-subtitle-generator` (ASS colors,
  ≤16 chars/line), bookend scenes excluded.
- Audio layout matches brief: narration back-to-back, silence only at opener/
  chapter cards, music low, ducking on, narration at section starts.
- Every slot has a `reason`.
- Timeline duration within ±10% of `script.total_duration_seconds` (+ bookends).

## Common Pitfalls

- **_Re-cutting or re-splitting at edit time_ to "add rhythm". Splitting belongs in
  the SCENE PLAN; the edit only places slots, it never invents boundaries. For a
  section the scene plan already produced sentence-shots.
- **Overlaying materials in the wrong order** (foreground under background) → the
  shot frame is broken. Always layer background → midground → foreground.
- **Splitting a material across the window** to make an "in/out" montage — materials
  OVERLAY the same window; a sequence of images is multiple shots, not one layered
  shot.
- Forgetting bookends have no narration, then placing a narration segment in an
  empty slot; or leaving a gap between narration segments (dead air between
  chapters).
- `render_runtime` set to anything but `"ffmpeg"`. Scene generation already
  happened at assets; compose is ffmpeg overlay + concat + burn + mux.
- HTML hex subtitle colors (`#FFFFFF`) → render BLACK. Use `&H00FFFFFF` via the
  ass-subtitle-generator skill.
- Word-by-word/karaoke subtitles — hard fail.
- Subtitle lines longer than ~16 chars that wrap off-screen — always short lines.
- Music at narration level, or without ducking.
- Bookends without `scene_opener`/`section_chapter_*` ids leaking into subtitle
  timing.
