# 003-04 - Frontend SPA

**Status:** done  **Spec:** issues/003-narration-synth-web-service.md  **Blocking:** 依赖 003-01（路由）、003-03（SSE 事件）

## 目标

单页面前端：textarea 输入 → 生成 → 进度条 → 历史列表 → 下载。

## 验收标准

1. 页面包含：多行 textarea（口播文案输入）、"生成视频"按钮、进度显示区域、历史任务列表。
2. 点击"生成"后：按钮禁用 + 显示"正在提交..."，进度区域显示阶段文字（通过 SSE 实时更新）。
3. SSE 断线自动重连（`EventSource` 原生行为）。
4. 生成完成后：进度区域显示"完成" + 下载链接，历史列表自动刷新。
5. 历史列表显示：文案前 50 字摘要、状态（pending/running/done/error）、创建时间、下载按钮。
6. 错误时显示红色提示（不吞错误）。
7. 样式简洁：深色背景（`#070b12`）+ 浅色文字，与军政口播调性一致。
8. 无外部 CDN 依赖（所有 CSS/JS 内联或本地文件）。
